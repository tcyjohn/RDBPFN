# Design: Signal-Group Feature Generation with Archetype Priors

**Date**: 2026-05-22 (revised 2026-05-23, round 3)
**Status**: Reviewed — contracts specified, ready for Phase 0
**Branch**: `feature/hsbm-temporal-refactor`

## Problem

Synthetic feature columns (12 `feature_N` per table) have two quality gaps vs real benchmarks:

| Metric | Synthetic (current) | Real Tab | Real Rel |
|--------|:---------:|:--------:|:--------:|
| avg \|corr\| p50 | 0.077 | 0.128 | 0.185 |
| feature var p50 | 2.04 | 14.15 | 76.21 |

Root cause: `feature_j = outputs_flat[random_index]` — each feature is one random hidden
unit. No shared structure induces correlation.

## Design Philosophy

- **HSBM (FK generation)**: latent hierarchy → block assignment → FK correlation
- **Signal Groups (feature generation)**: latent signal sources → feature group assignment → feature correlation

## Phase 0: Contracts (implement FIRST, no business logic)

### Contract 0.1 — RelationKey

```python
from collections import namedtuple
RelationKey = namedtuple("RelationKey", ["child_table", "fk_col_idx", "parent_table"])
```

All projectors, path encoders, caches, and debug logs use this key. Generated by a single
factory function:

```python
def make_relation_key(child_table: str, fk_col_idx: int, parent_table: str) -> RelationKey:
    return RelationKey(child_table=child_table, fk_col_idx=fk_col_idx, parent_table=parent_table)
```

### Contract 0.2 — PathEncoderSpec

- **Per-edge**, NOT per-table. L_p = num_levels of the parent for this FK edge.
- Architecture per edge: `Embedding_per_level (L_p levels × max_block × 4) → concat → Linear(L_p×4 → 8)`
- Multi-parent: per-edge path embedding → **mean-pool** → table-level path_signal `(seq_len, 8)`.
  Same philosophy as parent_signal.
- Stored in `nn.ModuleDict`, keyed by `RelationKey`.
- For `compute_hsbm_fk_ids_multi()`: `cluster_b` is shared across parents (shared latent variable).
  Each edge reads its prefix `cluster_b[:, :L_p]`. Different edges see different prefix
  lengths → different per-edge Linear input dims.
- Fallback when block_paths is None: path_signal = `zeros(seq_len, 8)`. Assignment to path
  group is still valid (basis projection of zero → zero contribution), but residual still
  fires. Only path_signal degrades, not the whole feature path.

### Contract 0.3 — TimeSignalSpec

- `time_features` shape `(seq_len, 11)` from `_prepare_time_features()`.
- `time_basis = time_features[:, 0:8]`, `time_gates = time_features[:, 8:11]`. Hard boundary.
- Normalization:
  - `time_basis_norm = time_basis / rms(time_basis) × group_scale_time`  (global RMS)
  - `time_gates_raw = time_gates`  (AS-IS, no RMS, no scale)
- Basis vectors **split**:
  - `B_time_basis`: `(K_time, 8)` = `(3, 8)` — projects normalized basis subspace
  - `B_time_gate`: `(K_time, 3)` = `(3, 3)` — projects raw gate subspace
- Feature construction for time group:
  ```
  proj = (time_basis_norm @ B_time_basis[k]) + (time_gates_raw @ B_time_gate[k])
  x_j += loading × proj
  ```
  This prevents the normalized basis subspace from being mixed with the un-normalized
  gate subspace in the projection.

### Contract 0.4 — FeatureGenMode

| HP | `use_signal_group_features=True` | `use_signal_group_features=False` |
|----|:---:|:---:|
| `archetype_perturb_std` | **active** | ignored |

| `block_wise_dropout` | **active** (MLP weight init) | **active** |

## Architecture

```
TableConfig / Schema Metadata
  │
  ├─→ Archetype Classifier ─→ Dirichlet α (per table, HP-perturbed)
  │       │
  │       └─→ Feature-to-Group Assignment (per table, fixed at init)
  │             └─→ per feature: group(s) + basis indices + loading sign×magnitude
  │
  └─→ Per-forward Call:
          │
          ├─→ Shared Signal Generators:
          │     time_signal    ← _prepare_time_features() → split basis(8) + gates(3)
          │     parent_signal  ← per-edge FK projection (CAUSAL_OUTPUT → 12), mean-pool
          │     path_signal    ← per-edge path embedding (L_p×4 → 8), mean-pool
          │
          ├─→ Group-Specific Normalization + group_scale:
          │     time:  basis(8) → global RMS × scale; gates(3) → AS-IS
          │     parent: global RMS × scale
          │     path:  global RMS × scale
          │
          └─→ Feature Construction:
                for each feature j:
                    for each assigned group g, basis index k:
                        proj_gk = signal_basis @ B_g_basis[k]
                                + signal_gate @ B_g_gate[k]  (time only)
                        x_j += sign_{j,g,k} × |magnitude|_{j,g,k} × proj_gk
                    x_j += ε_j   ← per-feature independent noise (NOT a group)
```

### Key Design Decisions

1. **residual is NOT a group** — per-feature additive noise, no shared basis, no group
   scale, no Dirichlet entry.
2. **Assignment fixed at table init** — group membership, basis indices, loading
   signs/magnitudes all sampled once at `__init__()`.
3. **Loading = sign × magnitude** — `sign ∈ {−1, +1}` (equal prob), `magnitude ~ LogNormal(μ, σ)`.
   Avoids `Normal(0, σ)` collapsing to zero and producing "residual-only" features.
4. **Per-edge path encoder** — L_p varies per parent (different num_levels). Per-edge
   `Linear(L_p×4 → 8)`. Multi-parent: mean-pool across edges. Same philosophy as parent_signal.
5. **B_time split** — `B_time_basis (3×8)` and `B_time_gate (3×3)`. Normalized basis
   and raw gates projected separately, then summed.
6. **v1: direct parent role only** — parent_signal only uses 1-hop FK edges.
7. **hsbm_locality = structural proxy** — `mean(Σ_l log(clusters_per_level_l))`, deterministic,
   no RNG dependency.
8. **`forward_without_input()` only for source tables** — archetype α masks parent/path.

## Component Details

### 1. Table Archetype → Dirichlet α

Four archetype signals:

| Signal | Source | Type |
|--------|--------|------|
| `is_source` | len(parent_tables) == 0 | bool |
| `is_timestamp` | `time_dim > 0` | bool |
| `num_parents` | count of direct FK edges | int |
| `hsbm_locality` | structural proxy (see §1a) | float |

Signal groups (excl. residual): `time`, `parent`, `path`.

**Archetype → base α**:

```
Source table:        active={time}, mask={parent, path}
                    α = [1.0,   —,    —]
Dependent non-ts:   α = [0.1,   0.55, 0.35]
Timestamp table:    α = [0.5,   0.25, 0.25]
Multi-parent:       α_parent = min(0.6, num_parents × 0.10)
                    Re-normalize among active groups after capping
```

Unavailable groups **masked** (α=0) regardless of archetype base mapping.

**HP perturbation**: `α_g = base_α_g × exp(η_g)`, `η_g ~ N(0, σ²_archetype)`.

#### 1a. hsbm_locality (Structural Proxy)

```python
def compute_hsbm_locality(hierarchies: list[list[int]]) -> float:
    """Deterministic structural proxy for HSBM connection concentration."""
    if not hierarchies:
        return 0.0
    per_edge = [sum(math.log(cpl) for _ in range(len(h))) for h in hierarchies]
    max_possible = max(per_edge) if per_edge else 1.0
    return float(np.mean([v / max_possible for v in per_edge])) if max_possible > 0 else 0.0
```

### 2. Feature-to-Group Assignment (fixed at init)

Per table, sampled once. For each of the 12 features:

1. Sample group weights from Dirichlet(α) over active groups
2. Select top-1 or top-2 groups (`max_groups_per_feature` HP, default=1)
3. For each selected group g, sample:
   - `K_assigned` basis indices from `{1, ..., K_g}` without replacement (default: 1)
   - `sign_{j,g,k} = random.choice([-1, +1])`
   - `magnitude_{j,g,k} ~ LogNormal(μ=log(0.6), σ=loading_sigma)`
   - `loading = sign × magnitude`

Basis indices, signs, and magnitudes stored as instance state.

### 3. Signal Generators (per forward call)

#### time_signal
- Source: `_prepare_time_features()` → `(seq_len, 11)`
- Split: `basis = time_features[:, 0:8]`, `gates = time_features[:, 8:11]`
- S_basis = 8, S_gates = 3

#### parent_signal (v1: direct role only)
- Per-edge projection: `parent_rows = parent.CAUSAL_OUTPUT[fk_ids[:, edge_idx]]`
  → `projectors[RelationKey](parent_rows)` → `(seq_len, 12)`
- Multi-edge: mean-pool → `(seq_len, 12)`
- No parents: `zeros(seq_len, 12)`
- Projectors stored in `nn.ModuleDict`, keyed by `RelationKey`

#### path_signal
- Source: `block_paths` from HSBM, shape `(child_size, L_max)` where `L_max = max(len(h) for h in hierarchies_parent)`
- Per-edge: `edge_path = block_paths[:, :L_p]` (prefix) → embed per level (dim=4) → concat → `Linear(L_p×4 → 8)` → `(seq_len, 8)`
- Multi-edge: mean-pool → `(seq_len, 8)`
- No paths: `zeros(seq_len, 8)`
- Path encoders stored in `nn.ModuleDict`, keyed by `RelationKey`

### 4. Group-Specific Normalization

```python
# time: split normalization
time_basis = time_signal[:, 0:8]
time_gates = time_signal[:, 8:11]
time_basis_norm = time_basis / rms(time_basis) * group_scale_time  # global RMS
time_gates_raw  = time_gates  # AS-IS

# parent: standard RMS
parent_out = parent_signal / rms(parent_signal) * group_scale_parent

# path: standard RMS
path_out = path_signal / rms(path_signal) * group_scale_path
```

### 5. Feature Construction

Basis vectors per group:

| Group | S_g | K_g | B_g_basis shape | B_g_gate shape |
|-------|-----|-----|-----------------|----------------|
| time | 8+3 | 3 | (3, 8) | (3, 3) |
| parent | 12 | 3 | (3, 12) | — |
| path | 8 | 2 | (2, 8) | — |

K_g = `min(3, max(2, ceil(S_g / 4)))`.

Per feature `j`:
```
x_j = 0
for each assigned group g:
    for each pre-assigned basis index k:
        proj = signal_basis_g @ B_g_basis[k]
        if g == time:
            proj += signal_gates_g @ B_time_gate[k]
        x_j += sign_{j,g,k} × magnitude_{j,g,k} × proj
x_j += ε_j   where ε_j ~ N(0, σ²_res)
```

Note: `sign_{j,g,k}` and `magnitude_{j,g,k}` are pre-sampled at init (fixed). Only
`ε_j` is random per forward call.

### 6. Data Flow

```
RDB.init_table_SCMs()
  │
  ├─→ Sample HSBM HPs per parent → compute hsbm_locality (structural proxy)
  ├─→ Determine RelationKeys: [(child_table, fk_col_idx, parent_table), ...]
  ├─→ Classify archetype → base α → perturb → final α
  │
  └─→ MLPSCM.__init__(archetype_params, relation_keys, parent_causal_dims, ...)
        ├─→ _sample_feature_groups(α) → per-feature: {groups, basis_idx, sign, magnitude}
        ├─→ _init_group_bases() → B_time_basis(3×8), B_time_gate(3×3),
        │                         B_parent(3×12), B_path(2×8)
        ├─→ _init_parent_projectors(relation_keys, parent_causal_dims)
        │     → nn.ModuleDict[RelationKey] = Linear(D_causal → 12)
        └─→ _init_path_encoders(relation_keys, L_per_edge)
              → nn.ModuleDict[RelationKey] = PathEncoder(L_p)

TableGenerator.generate_data()
  │
  ├─→ _compute_hsbm_fk_ids()
  │     └─→ returns (fk_ids, block_paths)  ← MODIFIED
  │
  └─→ MLPSCM.forward_with_input(parent_data_list, fk_ids, block_paths)
        │
        ├─→ [existing] MLP forward → CAUSAL_OUTPUT, FULL
        ├─→ [NEW] _build_time_signal() → (seq_len, 11), split basis/gates
        ├─→ [NEW] _build_parent_signal() → per-edge project + mean-pool → (seq_len, 12)
        ├─→ [NEW] _build_path_signal() → per-edge embed + mean-pool → (seq_len, 8)
        ├─→ [NEW] _normalize_signals() → group-specific RMS/gates-ASIS + scale
        └─→ [NEW] _construct_features() → X[MASK_TYPE.X] (seq_len, 12)

forward_without_input(): only for source tables. α masks parent/path.
```

## Verification

### Standard metrics

1. Smoke test: 20 RDBs, 0 errors
2. avg |corr| p50 ≥ 0.12
3. feature var p50 ≥ 10
4. No regression: timestamp KS-test p > 0.05; label distribution shift < 0.05
5. `use_complex_tasks=False` works
6. `use_signal_group_features=False` produces identical output to pre-change code

### Extended audit suite

7. **Group occupancy audit**: per archetype, verify 12 features' group assignment ratios
   match α expectations. Source table → all features in time group.
8. **Loading audit**: histogram of `|loading|` per feature. Median |loading| ≥ 0.3;
   no feature has all |loadings| < 0.05 (residual-only detector).
9. **Multi-parent audit**: two FK edges pointing to same parent but with different
   roles (different fk_col_idx) → verify projectors and path encoders are distinct
   `nn.Module` instances (different `RelationKey`).
10. **Path fallback audit**: when block_paths=None, path_signal is all-zeros; feature
    construction still succeeds; path-group-assigned features get zero contribution
    from path but still get residual noise.
11. **Signal energy audit**: after normalization, RMS(time_basis) ≈ group_scale_time,
    RMS(parent) ≈ group_scale_parent, RMS(path) ≈ group_scale_path. gates unchanged.
12. **Role sensitivity check**: for a table with 2 FK edges to the same parent table
    (different fk_col_idx), swap the FK order in parent_data_list and fk_ids →
    parent_signal should change (different projector applied to different parent rows).
