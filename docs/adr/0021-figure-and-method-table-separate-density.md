# Separate temporal-history density from the three mechanisms in Figure 1 and Table 1

Figure 1a will use one customer row and repeated order or event rows rather than duplicate primary keys. Figure 1b and the method comparison table will present hierarchical FK connectivity, calendar-aware temporal structure, and grouped latent feature sources as the three semantic mechanisms, while showing \(S\sim U(5,20)\) temporal-history density in a visually separate corpus-setting box or row. The unchanged DFS interface, PFN backbone, objective, and inference protocol remain explicit.
