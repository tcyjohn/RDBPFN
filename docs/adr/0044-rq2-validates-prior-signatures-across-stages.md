# RQ2 validates prior signatures across stages

RQ2 asks, “Which Intended Prior Signatures Are Observable in Generated Databases and DFS Tasks?” It validates hierarchical connectivity, calendar-aware time, grouped feature dependence, and source-row cardinality at their generated-database intervention level, then traces grouped feature dependence into the DFS task representation. This ordering makes the design-to-evidence map in Method the explicit contract for the Results diagnostics and supersedes ADR-0027's placement of this evidence in RQ3.
