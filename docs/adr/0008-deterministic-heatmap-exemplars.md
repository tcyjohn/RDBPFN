# Select heatmaps by a deterministic median-exemplar rule

Because the final R2 and R3 H5 corpora do not retain source RDB or task identifiers, their DFS tasks cannot be paired. Each R2, R3, and real-RDB heatmap will therefore use the eligible task closest to that corpus's median normalized effective rank, selected without reference to appearance or model performance, and will be accompanied by the full-corpus effective-rank distribution.
