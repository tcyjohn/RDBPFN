# Retain the legacy-materialization Mix as a secondary main-text checkpoint

The main paper will retain the 0.7118 Mix checkpoint because it is the highest observed documented operating point, but it will remain secondary rather than define the paper's core comparison. It must be labeled as combining v6.2 with the earlier 1,169-task R3 materialization and cannot support a causal or source-aligned mixing claim. A main-table footnote will disclose that the corrected direct-R3 Mix reached 0.7079, with its complete results placed in the appendix, preventing the legacy checkpoint from being presented as the source-aligned outcome.
