# Only the complete operating point receives a method name

The main manuscript names the complete high-cardinality/grouped-on operating point SA-RDB-PFN. The other three sensitivity checkpoints are referenced only by their high/low source-row-cardinality and grouped-on/off coordinates; `R3`, `joint-removal`, and additional variant names are omitted from the main text. This makes every RQ3 comparison self-describing.
