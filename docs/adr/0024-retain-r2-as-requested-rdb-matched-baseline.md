# Retain R2 as the requested-RDB-matched baseline

RDB-PFN-Small remains a central RQ1 baseline because it and SA-RDB-PFN each request 1,024 source RDBs and match checkpoint initialization, PFN architecture, and optimizer horizon. The manuscript will call it the requested-RDB-matched baseline and report raw cells, completed RDBs, stored tasks, and materialization policy separately; these disclosures qualify the comparison without removing or marginalizing R2.
