# Report raw source-database cell scale in the main operating-point table

The main Results table will report requested and completed source databases,
stored relational tasks, raw table cells, and AUROC. For the published RDB-PFN
continuation corpus, the requested-source-database entry will say “not reported
in the paper,” while raw cells will be marked as an estimate of approximately
63.53B reconstructed from the released 480K-source-RDB generation schedule and
Small/Large dimension configurations. A note will distinguish this released-code
reconstruction from quantities reported by the paper. The caption will state
that stored tasks contain 600 rows and the core checkpoints use 112,000
optimizer steps, making SA-RDB-PFN's higher density relative to the compact
control and smaller estimated total scale relative to full RDB-PFN visible in
the same accounting.
