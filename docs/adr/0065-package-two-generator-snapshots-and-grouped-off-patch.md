# Package two generator snapshots and a grouped-source-off patch

The anonymous package preserves the historical SA-RDB-PFN (R3) and
RDB-PFN-Small (R2) generator snapshots because the compact control differs
substantially across the generator stack. The two grouped-source-off sensitivity
coordinates are represented by the small R25 configuration patch relative to
R3, while high and low source-row cardinality remain explicit configuration
profiles; we do not replace the executed variants with an unvalidated
submission-time generator refactor.
