# Use component-specific data evidence

The analysis will not force data-prior and entity-aware mechanisms into one metric family. R2--R3 will adapt the original RDB-PFN correlation-heatmap analysis and add paired raw-RDB plus aggregate DFS statistics, while R3--v6.2 will use entity-exposure measurements and task-wise performance deltas because entity identifiers act primarily through an attention side channel rather than ordinary feature correlation.
