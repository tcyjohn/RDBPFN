# Move the entity-aware package and mixtures out of the main manuscript

The main manuscript will define and evaluate only SA-RDB-PFN. The separately materialized v6.2 entity-aware package, same-entity attention bias, legacy Mix, and source-aligned Mix move to a supplement section titled “Exploratory Entity-Aware Extension (v6.2; Not Part of SA-RDB-PFN),” because they do not belong to the reported method and would reintroduce an unsupported persistent-identity storyline.
