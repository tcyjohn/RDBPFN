# Running example connects the task to prior design

The Introduction uses customer churn as a running example in both the opening
and design-requirement paragraphs. Linked orders and products explain
reachability, cutoff-valid records explain availability, shared attribute
signals explain content dependence, and source-table population explains
source-row cardinality. The cardinality explanation remains at the generated
source-table level and does not imply more PFN support rows or guaranteed
additional history for every target row.
