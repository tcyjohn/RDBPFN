# Retain source-row density as an empirical setting

The Method retains a short standalone subsection for the source-row density setting because the sensitivity grid shows that it is empirically consequential. The subsection defines its direct operation—generating more rows in tables with schema out-degree at least one—and keeps it separate from both the three semantic mechanisms and the independently controlled PFN support-row budget.
