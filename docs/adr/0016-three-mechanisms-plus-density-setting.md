# Separate three structural mechanisms from the temporal-history density setting

The manuscript will organize SA-RDB-PFN around hierarchical foreign-key connectivity, calendar-aware temporal structure, and grouped latent feature sources. The \(S\sim U(5,20)\) expansion applies to entity tables, defined structurally by schema out-degree at least one; timestamp presence is not its eligibility condition. It remains part of the reported operating point but is described separately as a temporal-history density setting. The public method description names its model-visible effects: greater source-table cardinality and, together with the temporal prior, denser context for DFS. It does not mention internal row-group assignment, persistent identity, or entity history.
