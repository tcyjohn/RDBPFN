# RQ1 tests complete-prior utility

RQ1 asks, “Does the Complete SA-RDB-PFN Relational Prior Improve Compact-Corpus Relational In-Context Learning?” It evaluates the four-dimensional prior as one operating point: RDB-PFN-Small is the requested-RDB-matched compact control, and the published 1.2M-task checkpoint is the stored-task scale reference. Dimension-specific evidence belongs to the later structure and sensitivity questions.
