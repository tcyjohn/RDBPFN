# Scientific gap combines DFS-oriented design and cross-stage validation

The Introduction frames a two-layer scientific gap. First, for DFS-based
relational in-context learning, the prior-design question is how synthetic
relational structure should be organized around information exposed to the
learner: reachability, availability, and content dependence, together with
source-row cardinality. Second, the validation question is how to connect those
design choices to generated-database signatures, model-visible DFS
representations where measured, and compact-corpus predictive evidence. Stored
task count is an experimental condition and headline empirical result rather
than the scientific gap itself.
