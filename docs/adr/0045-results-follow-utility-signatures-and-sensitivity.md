# Results follow utility, signatures, and sensitivity

The Results section uses three questions in scientific dependency order. RQ1 asks whether the complete four-dimensional relational prior improves compact-corpus relational in-context learning; RQ2 validates intended prior signatures in generated databases and DFS tasks; RQ3 quantifies predictive sensitivity to source-row cardinality and grouped feature sources across the four fixed operating points. This order replaces the earlier task-efficiency, sensitivity, then mechanism sequence and fixes the sensitivity grid as RQ3.
