# ADR-0029: Use SA-RDB-PFN as the only main-text method name

## Status

Accepted

## Decision

The main manuscript will consistently call the reported method and operating
point **SA-RDB-PFN**. “R3” is an internal generator and experiment-provenance
label, not a second method name. It may appear only in the Technical Supplement,
technical audit records, or a necessary provenance note.

Variant labels will be expressed relative to SA-RDB-PFN, for example:

- SA-RDB-PFN (\(S=1\));
- SA-RDB-PFN without signal groups;
- SA-RDB-PFN (\(S=1\), without signal groups), if the pending result completes.

The main text will not alternate between “R3” and “SA-RDB-PFN.”
