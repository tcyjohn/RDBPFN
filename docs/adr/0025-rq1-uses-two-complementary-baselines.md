# Use R2 and full RDB-PFN as complementary RQ1 baselines

RQ1 will use RDB-PFN-Small to measure predictive improvement when both compact operating points request 1,024 source RDBs, and the full published RDB-PFN checkpoint to contextualize task and raw-generation scale. The first comparison reports the \(+0.0178\) AUROC difference; the second reports approximately 99.9% fewer stored tasks and 98.4% fewer estimated raw cells while describing the narrowed performance gap.
